# dimore spec

- アプリ名: dimore (dim + more)
- 配布形態: adb install によるAPKインストール (ストア配布なし、APK直接タップ不可 — Enhanced Confirmation Mode による権限制限のため)
- 対応バージョン: Android 16
- バージョニング: v{n}.0.0 形式。バージョン番号は整数としてバージョンファイルに記録する。CLAUDE.mdで更新毎の+1を強制する

## 機能

- 画面上にソフトウェアオーバーレイを被せて表示を暗くする
- オン/オフの切り替えと明度調整ができる

## 通知

- アプリ起動中 (オーバーレイ有効時): pinned通知を常に表示する
  - 通知からオン/オフの切り替えができる
  - 通知から明度調整ができる (技術的に困難な場合は、通知タップでアプリ内の明度調整UIに遷移する形でもよい)
- オーバーレイ無効時の通知:
  - 設定で挙動を選択できる
  - 選択肢: 常に表示 / 一定時間後に非表示
  - 「一定時間後に非表示」の時間選択肢: 0秒 (実質即時非表示), 10秒
  - 0秒と10秒の2択のみ

## アプリ設定UI

- 起動時自動有効化オプション (アプリ起動時にオーバーレイを自動でオンにするかどうか)
- オフ時の通知挙動の設定 (上記「オーバーレイ無効時の通知」の選択)
