# dimore spec

- アプリ名: dimore (dim + more)
- 配布形態: APK インストール (ストア配布なし)。adb install 推奨。APK 直接タップでもインストール可能だが、Enhanced Confirmation Mode により一部権限が制限されるため adb/Shizuku で権限を有効化する必要がある
- 対応バージョン: Android 16
- バージョニング: v{n}.0.0 形式。バージョン番号は整数としてバージョンファイルに記録する。CLAUDE.mdで更新毎の+1を強制する

## 権限

- オーバーレイ権限: オーバーレイ描画に必須。設定画面への遷移UIをアプリ内に設置
- 通知権限: 通知表示に必要。アプリ起動時にランタイム権限を要求する
- Enhanced Confirmation Mode: APK直接タップインストールでは上記権限が制限される。adb install でインストールするか、adb/Shizuku で権限を有効化する

## Shizuku 連携 (オプショナル)

- Shizuku がインストール・起動済みの場合、アプリ内からオーバーレイ権限を自動付与できる
- Shizuku 未導入の場合は従来通り手動で設定画面から許可する
- Shizuku がなくてもアプリは動作する

## メイン画面 UI

権限の状態に応じて表示を切り替える。画面復帰時に権限状態を再チェックする。

### オーバーレイ権限

- 未許可:
  - 「オーバーレイ権限が必要です」テキスト表示
  - 「権限を許可する」ボタン → システム設定画面に遷移
  - Shizuku が利用可能かつ権限あり → 「Shizuku で権限を付与」ボタン → 自動付与
- 許可済み:
  - オン/オフトグルボタン
  - 明度スライダー (0% - 90%)
  - 設定ボタン

### 通知権限

- 未許可:
  - 「通知権限がありません」警告テキスト表示
  - 「通知を許可する」ボタン → 権限ダイアログを表示
- 許可済み: 表示なし
- 起動時に未許可なら自動で権限ダイアログを表示する

### Shizuku

- 未インストール / 未起動: Shizuku 関連の UI を表示しない
- 起動済み・権限未付与: 「Shizuku 権限を許可する」ボタン → 権限要求
- 起動済み・権限付与済み: オーバーレイ権限未許可時に「Shizuku で権限を付与」ボタンを表示

## 機能

- 画面上にソフトウェアオーバーレイを被せて表示を暗くする
- オン/オフの切り替えと明度調整ができる

## 通知

- オーバーレイ有効時: pinned通知を常に表示する
  - 通知からオン/オフの切り替えができる
  - 通知から明度調整ができる (通知タップでアプリ内の明度調整UIに遷移する形でもよい)
- オーバーレイ無効時の通知:
  - 設定で挙動を選択できる
  - 選択肢: 常に表示 / 一定時間後に非表示
  - 「一定時間後に非表示」の時間選択肢: 0秒 (実質即時非表示), 10秒
  - 0秒と10秒の2択のみ

## アプリ設定UI

- 起動時自動有効化オプション (アプリ起動時にオーバーレイを自動でオンにするかどうか)
- オフ時の通知挙動の設定 (上記「オーバーレイ無効時の通知」の選択)
